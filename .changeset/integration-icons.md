**Integration icons now survive the add flow and can be edited**

New OpenAPI, GraphQL, and MCP integrations persist an icon derived from their API or server URL, so the brand shown in the add preview remains visible after creation. Every saved integration also gets a shared Icon URL field that accepts an HTTP(S) image URL and updates the catalog, sidebars, command palette, admin view, and toolkit editor consistently.
